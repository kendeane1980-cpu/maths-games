# Maths Games

Timed column-addition games for children, made to be played on a phone.

**Play:** https://kendeane1980-cpu.github.io/maths-games/

| Game | What it is |
| --- | --- |
| [Beat the Pencil](beat-the-pencil.html) | Finish your sums before the pencil gets used up. Choose 2 or 3 digits, with or without carrying, how many sums and how much time. |
| [Penalty Shootout](penalty-shootout.html) | Every right answer is a goal. Race the clock on your own, or play 2 players on one phone: alternate kicks, each player picks their own level, most goals wins and the fastest time breaks a tie. |

## How it works

- Each game is a single HTML file with no build step and no server.
- Sums are generated fresh in the browser every game.
- Best times, names, kits and settings are saved in the phone's own browser storage (`localStorage`). Nothing is sent anywhere.
- Fonts come from Google Fonts. Everything else, including the sounds, is made in the page.

## Updating

Edit or replace the `.html` files and push to `main`. GitHub Pages republishes the site within a minute or two.

## Add to your home screen

- **iPhone:** open a game in Safari, tap Share, then Add to Home Screen.
- **Android:** open a game in Chrome, tap the ⋮ menu, then Add to Home screen.
